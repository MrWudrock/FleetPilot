# Dispatch Agent

Автоматическая классификация заявок и назначение водителей.

## Назначение

- Приём заявок из разных источников (email, Excel, API, TMS)
- Классификация: FTL/LTL, срочность, тип груза
- Матчинг ТС и водителей по критериям
- Предложение top-3 назначений с обоснованием
- Human-in-the-loop: диспетчер подтверждает

## Метрики эффективности

| Метрика | Baseline | Целевое |
|---------|----------|---------|
| Время обработки заявки | 2.8 ч | 0.4 ч (−86%) |
| Точность классификации | 78% | 94% |
| Успешные назначения | 65% | 89% |
| Отмены из-за ошибок | 12% | 3% |

## Конфигурация

См. `config.yaml`.

## Интеграции

- **Email** — парсер входящих заявок
- **Excel/CSV** — массовый импорт
- **Master TMS / ANTOR** — двусторонняя синхронизация
- **Omnicomm / СтавТРЭК** — доступность и позиции ТС

## Промпты

- `system.md` — роль агента
- `classify_order.md` — классификация заявки
- `assign_driver.md` — назначение водителя

## Правила

- `ftl_ltl_rules.yaml` — определение FTL/LTL
- `assignment_weights.yaml` — веса факторов назначения
