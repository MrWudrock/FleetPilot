# Fuel Agent

Контроль расхода топлива, обнаружение сливов, рейтинг водителей.

## Назначение

- Мониторинг уровня топлива в реальном времени (ДУТ)
- Обнаружение подозрительных сливах
- Анализ стиля вождения
- Рейтинг водителей по расходу топлива
- Ежемесячные отчёты по экономии

## Метрики эффективности

| Метрика | Baseline | Целевое |
|---------|----------|---------|
| Расход топлива | 100% | −10–26% |
| Обнаружение сливов | 45% | 92% |
| Ложные алерты | 35% | <8% |
| Экономия/год (30 ТС) | ₽0 | ₽970K–₽1.4M |

## Конфигурация

См. `config.yaml`.

## Интеграции

- **Omnicomm Online** — ДУТ, CAN, GPS
- **СтавТРЭК** — GPS, пробег
- **АЗС** — база заправок

## Промпты

- `system.md` — роль агента
- `drain_alert.md` — формирование алерта о сливе
- `monthly_report.md` — генерация отчёта

## Правила

- `drain_thresholds.yaml` — пороги обнаружения сливов
- `consumption_baselines.yaml` — базовые нормы расхода
- `driving_scores.yaml` — критерии оценки водителей
