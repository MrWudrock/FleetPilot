# Maintenance Agent

Предиктивное техническое обслуживание по телематике и пробегу.

## Назначение

- Прогнозирование ТО по пробегу, моточасам, CAN-кодам
- Предупреждение о критических состояниях за 7–14 дней
- Планирование графика ТО
- Прогнозирование потребности в запчастях
- Интеграция с 1С (пост-MVP)

## Метрики эффективности

| Метрика | Baseline | Целевое |
|---------|----------|---------|
| Незапланированные простои | 100% | −15% |
| Стоимость ремонта | 100% | −10% |
| Время простоя ТС | 100% | −20% |
| Точность прогноза | 60% | 85% |

## Конфигурация

См. `config.yaml`.

## Интеграции

- **Omnicomm / СтавТРЭК** — пробег, моточасы, CAN
- **1С:Предприятие** — документы ТО (пост-MVP)
- **Поставщики запчастей** — цены и наличие (пост-MVP)

## Промпты

- `system.md` — роль агента
- `maintenance_forecast.md` — генерация прогноза ТО
- `parts_prediction.md` — прогноз запчастей

## Правила

- `maintenance_intervals.yaml` — интервалы ТО по типам ТС
- `dtc_codes.yaml` — описание DTC-кодов ошибок
