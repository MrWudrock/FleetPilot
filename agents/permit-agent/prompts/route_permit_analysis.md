# Анализ маршрута для спецразрешения

## Вход

- Точка А, точка Б, промежуточные точки
- Габариты груза: длина, ширина, высота (м)
- Масса (т), нагрузка на оси (т)
- Параметры автопоезда
- Данные маршрута из Росдормониторинг (если есть)

## Задачи

1. Превышает ли груз нормы 2.55×4×12 м?
2. Какие участки с ограничениями по оси / габариту?
3. Нужен ли ПОДД?
4. Особые условия (ремонт, временные знаки)?
5. Есть ли более безопасный альтернативный маршрут?
6. Ориентировочная компенсация владельцу дороги (если данные есть)

## Формат ответа

Краткое резюме для диспетчера (3–5 предложений) + structured JSON из system.md.
