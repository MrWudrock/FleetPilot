# Route Agent

Оптимизация маршрутов с учётом пробок, погоды, загрузки и ограничений ТС.

## Назначение

- Приём заявки на доставку (FTL/LTL)
- Расчёт оптимального маршрута (OR-Tools VRP)
- Учёт временных окон доставки
- Предложение альтернатив с обоснованием
- Мониторинг отклонений от маршрута

## Метрики эффективности

| Метрика | Baseline | Целевое |
|---------|----------|---------|
| Пробег (км) | 100% | −8–15% |
| Время в пути | 100% | −12–20% |
| Расход топлива | 100% | −10–18% |
| Стоимость рейса | 100% | −10–16% |

## Конфигурация

См. `config.yaml` — пороги, веса, лимиты.

## Интеграции

- **Yandex Maps API** — матрица расстояний + трафик
- **2GIS** — fallback для регионов без Yandex
- **Omnicomm / СтавТРЭК** — текущие позиции ТС

## Промпты

- `system.md` — роль агента, формат вывода
- `route_optimization.md` — генерация маршрута
- `deviation_explanation.md` — объяснение отклонений

## Правила

- `time_windows.yaml` — временные окна доставки
- `vehicle_constraints.yaml` — ограничения по ТС (грузоподъёмность, габариты)
