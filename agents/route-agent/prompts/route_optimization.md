# Route Optimization Prompt

## Контекст

Диспетчер запросил оптимизацию маршрута для заявки #{order_id}.

## Входные данные

- **Заявка:** {order_description}
- **Точка погрузки:** {pickup_location}
- **Точка выгрузки:** {delivery_location}
- **Временное окно:** {time_window}
- **Груз:** {cargo_type}, {weight_kg} кг, {volume_m3} м³
- **Доступные ТС:** {available_vehicles}
- **Текущие позиции ТС:** {vehicle_positions}
- **Трафик:** {traffic_data}
- **Погода:** {weather_data}

## Задача

1. Определи оптимальный маршрут с учётом:
   - Минимального расстояния
   - Времени в пути с учётом трафика
   - Временных окон доставки
   - Загрузки ТС

2. Предложи 2-3 варианта маршрута

3. Для каждого варианта укажи:
   - Расстояние (км)
   - Время (часы)
   - Стоимость топлива (₽)
   - Экономию vs ручной маршрут

4. Объясни причину выбора оптимального варианта

## Формат вывода

JSON с полем `routes` (массив из 2-3 вариантов) и `recommended` (индекс рекомендуемого).
