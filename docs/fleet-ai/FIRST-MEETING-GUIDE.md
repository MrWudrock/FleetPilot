# FleetPilot — Гайд первой встречи с заказчиком

**Версия:** 1.0 · **Дата:** 23.06.2026  
**Цель:** собрать ТЗ на IT-услугу / пилот FleetPilot (автопарк + негабарит / спецразрешения)

---

## 1. До встречи (30–60 мин подготовки)

| Шаг | Действие |
|-----|----------|
| 1 | Изучить сайт компании, автопарк (оценка по госномерам / 2GIS / тендерам) |
| 2 | Проверить: есть ли негабарит (спецтехника, длинномеры, тяжеловес) |
| 3 | Уточнить: Omnicomm / СтавТРЭК / Росдормониторинг (ЛК на urm.safe-route.ru) |
| 4 | Подготовить **цель встречи**: discovery, не «продать всё» |
| 5 | Отправить agenda: 45 мин, список тем, запрос на запись (если ОК) |
| 6 | Открыть шаблон: [`meeting-protocol-template.md`](meeting-protocol-template.md) |

**Цель встречи FleetPilot:** понять боль, границы MVP, интеграции, критерии ROI, готовность к пилоту.

---

## 2. Структура встречи (45–60 мин)

### Блок 0 — Открытие (5 мин)

- Представление, цель: «понять задачу и оценить fit с FleetPilot»
- Согласие на запись / протокол
- Кто в комнате: ЛПР, диспетчер, руководитель автопарка, юрист (для негабарита)

### Блок 1 — Бизнес-контекст (10 мин)

**Вопросы:**

1. Сколько ТС в автопарке? Какой тип (FTL, негабарит, сборные)?
2. Какая **главная боль** сейчас: топливо, диспетчеризация, маршруты, ТО, **оформление спецразрешений**?
3. Почему **сейчас** (триггер: штрафы, сливы, потеря клиента, рост негабаритных рейсов)?
4. Операционный бюджет / год (диапазон)?

### Блок 2 — Текущий процесс (10 мин)

**Обычный рейс:**

- Как принимается заявка? (email, Excel, TMS, телефон)
- Сколько времени на одну заявку? (baseline: 2.8 ч)
- Как назначается ТС и водитель?

**Негабарит (если релевантно):**

- Кто оформляет спецразрешения? (диспетчер / отдельный специалист / аутсорс)
- Используете **Росдормониторинг**? Как часто?
- Сколько времени на один маршрут А→Б с согласованием?
- Были ли штрафы / отказы / переделка ПОДД?

### Блок 3 — Технический контур (10 мин)

| Система | Вопрос |
|---------|--------|
| GPS | Omnicomm / СтавТРЭК / другое? API доступен? |
| TMS | Master TMS / ANTOR / Excel? |
| Росдормониторинг | ЛК есть? Логин корпоративный? |
| Документы | ЭТрН, 1С, шаблоны ПОДД? |
| Данные | Требования 152-ФЗ, on-prem, облако РФ? |

### Блок 4 — Ожидания и границы MVP (10 мин)

1. Что **обязательно** в первой версии (4 агента + Permit Agent)?
2. Что можно **отложить** на этап 2?
3. **Критерии успеха пилота** (измеримые): ₽ экономии, −% времени на заявку, −часов на спецразрешение
4. Сроки, бюджет, кто согласует результат

### Блок 5 — Закрытие (5 мин)

- Краткое резюме услышанного (цель, scope, риски)
- **Следующий артефакт**: протокол + черновик ТЗ / карта процессов / список уточняющих вопросов
- Дата follow-up (в течение 48 ч)

## 3. Чеклист вопросов (распечатать)

### Бизнес

- [ ] Проблема и почему сейчас?
- [ ] Кто пользователи (роли)?
- [ ] Критерии успеха / приёмки?

### Операции

- [ ] Текущий процесс «как есть»
- [ ] Целевой процесс «как будет»
- [ ] Объём заявок / рейсов в день

### Негабарит / Permit Agent

- [ ] Доля негабаритных перевозок (%)
- [ ] Габариты типичного груза (Д×Ш×В, масса, нагрузка на ось)
- [ ] Регионы маршрутов
- [ ] Нужен ли автоматический анализ маршрута в Росдормониторинге?
- [ ] История разрешений (номера, типовые маршруты)

### IT

- [ ] Интеграции и API-ключи
- [ ] Безопасность, ПДн, хостинг
- [ ] Команда клиента для пилота (1 admin + 1 диспетчер)

## 4. Сразу после встречи (в тот же день)

| # | Действие | Срок |
|---|----------|------|
| 1 | Протокол встречи (решения, открытые вопросы) | 2–4 ч |
| 2 | Структурировать требования: функциональные / нефункциональные | 2–4 ч |
| 3 | Выделить **спорные места** → письмо с уточнениями | 24 ч |
| 4 | Отправить **резюме на согласование** заказчику | 24–48 ч |
| 5 | Черновик ТЗ или one-pager пилота | 48–72 ч |
| 6 | Внутренняя оценка (SP / срок / риски) — **не начинать разработку вслепую** | после согласования |

## 6. Связь с продуктом FleetPilot

| Боль на встрече | Модуль FleetPilot |
|-----------------|-------------------|
| Топливо, сливы | Fuel Agent + Omnicomm |

| Маршруты, пробки | Route Agent + Yandex Maps |
| ТО, простои | Maintenance Agent |
