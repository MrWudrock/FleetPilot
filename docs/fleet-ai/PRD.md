## 1. Executive Summary

### 1.1 Что строим

**FleetPilot** — B2B SaaS-платформа с ИИ-агентами, которая автоматизирует ключевые процессы транспортной компании **поверх уже установленных систем** (GPS, ДУТ, TMS). Пользователь подключает Omnicomm / СтавТРЭК / Master TMS — система запускает агентов:

- **Route Agent** — оптимизация маршрутов с учётом пробок, погоды, загрузки (+ интеграция мониторинга ТС)
- **Dispatch Agent** — приём заявок, классификация, назначение водителей (2.8 ч → 0.4 ч)
- **Fuel Agent** — контроль топлива, сливы, стиль вождения (экономия 10–60%)
- **Maintenance Agent** — предиктивное ТО по телематике

### 1.2 Почему сейчас

- Российские TMS/GPS достигли зрелости (Omnicomm, AXELOT, «Умная логистика») — **данные есть, AI-слоя нет**
- Топливо = 35% бюджета; ROI GPS+ДУТ доказан (окupaемость 3–4 мес.)
- ЭТрН и цифровизация документооборота — регуляторный push
- LLM + agent orchestration готовы для operational workflows с human-in-the-loop

### 1.3 Бизнес-модель

| Tier | Price | Includes |
|------|-------|----------|
| **Starter** | ₽29 000/мес | до 15 ТС, Route + Fuel Agent |
| **Pro** | ₽49 000/мес | до 30 ТС, все 4 агента, 3 seats |
| **Business** | ₽89 000/мес | до 50 ТС, TMS sync, ЭТрН, priority support |
| **Enterprise** | от ₽1.2M/год | Unlimited, on-prem, custom integrations |

**Founding offer (первые 10 клиентов):** ₽49K/мес × 6 мес · onboarding бесплатно · lock ₽59K на 12 мес.

### 1.4 North Star Metric

**₽ экономии на автопарк / месяц**, подтверждённая клиентом в ROI dashboard.

## 3. User Stories (MVP)

### Epic 1: Integration Hub

**US-1.1** Как админ, я подключаю Omnicomm / СтавТРЭК / MSS GLONASS по API-ключу, чтобы видеть все ТС на одной карте.

**Acceptance:**
- Поддержка Omnicomm, СтавТРЭК, MSS (MVP)
- Sync каждые 30 сек; fallback polling 2 мин
- Mapping vehicle_id ↔ госномер ↔ водитель

**US-1.2** Как админ, я подключаю Master TMS / ANTOR для двусторонней синхронизации заявок.

### Epic 2: Route Agent

**US-2.1** Как диспетчер, я получаю оптимизированный маршрут с учётом пробок и временных окон доставки.

**Acceptance:**
- Сокращение пробега ≥8% vs ручной маршрут (benchmark)
- Интеграция Yandex Maps / 2GIS Routing API
- Human approval перед отправкой водителю

**US-2.2** Как диспетчер, я вижу отклонения от маршрута в реальном времени с алертами.

### Epic 3: Dispatch Agent

**US-3.1** Как диспетчер, я загружаю заявку (email/Excel/API) — агент классифицирует, предлагает назначение водителя/ТС.

**Acceptance:**
- Классификация: FTL/LTL, срочность, тип груза
- Предложение top-3 назначений с обоснованием
- Время обработки ≤5 мин (vs 2.8 ч baseline)

### Epic 4: Fuel Agent

**US-4.1** Как руководитель автопарка, я вижу dashboard расхода топлива по ТС/водителям/маршрутам.

**US-4.2** Как руководитель, я получаю алерты о подозрительных сливах с confidence score.

**Acceptance:**
- Данные с ДУТ Omnicomm / CAN
- Алерт: confidence ≥0.85 → auto-notify; <0.85 → human review
- Отчёт «экономия vs baseline» ежемесячно

### Epic 5: Maintenance Agent

**US-5.1** Как механик, я получаю прогноз ТО по пробегу, моточасам, телематике.

**Acceptance:**
- Прогноз за 7–14 дней до критического состояния
- Интеграция с 1С (post-MVP) или Excel export

### Epic 6: ROI Dashboard

**US-6.1** Как комдиректор, я вижу ROI по каждому агенту и суммарную экономию.

### Epic 7: Permit Agent (негабарит · Росдормониторинг) — NEW

**US-7.1** Как диспетчер негабарита, я ввожу габариты груза и точки А→Б — агент анализирует маршрут через Росдормониторинг и подсказывает необходимость ПОДД и особые условия.

**US-7.2** Как руководитель автопарка, я проверяю статус спецразрешения по номеру и госномеру ТС.

**Acceptance:**
- Интеграция с реестром разрешений (фаза 1) и ЛК urm.safe-route.ru (фаза 2)
- Human-in-the-loop перед подачей заявки
- RAG по 257-ФЗ, ПП №12 для рекомендаций ПОДД
- Audit log всех запросов к Росдормониторингу (152-ФЗ)

См. [`ROSDORMONITORING-INTEGRATION.md`](ROSDORMONITORING-INTEGRATION.md)

## 7. AI/ML логика

| Agent | Model | Logic |
|-------|-------|-------|
| Route | OR-Tools + LLM | Optimization + natural language constraints |
| Dispatch | Claude Sonnet | Classification + assignment reasoning |
| Fuel | Rules + anomaly ML | Threshold + isolation forest on fuel deltas |
| Maintenance | Rules + regression | Mileage/hours + telematics patterns |

**Human-in-the-loop:** все назначения маршрутов и водителей требуют approval диспетчера в MVP.

## 8. Нефункциональные требования

## 9. Риски

| Риск | Mitigation |
|------|------------|
| API вендоров закрыты/нестабильны | Adapter pattern; fallback CSV import |
| Ложные алерты Fuel Agent | Confidence gating + human review |
| Сопротивление диспетчеров | «Агент предлагает — вы решаете» UX |
| Конкуренция Omnicomm analytics | Фокус на multi-vendor + dispatch AI |
