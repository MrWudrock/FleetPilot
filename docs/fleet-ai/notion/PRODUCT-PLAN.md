## 1. Overview

| Поле | Значение |
|------|----------|
| **Product name** | FleetPilot ([fleetpilot.ru](https://fleetpilot.ru)) |
| **One-liner** | SaaS-платформа для управления автопарком: трекинг, телематика, ИИ-агенты, финансовая аналитика и интеграции с Wialon, TMS, Росдормониторинг и 1С. |
| **Vision** | Дать владельцам и операторам автопарков **единую систему**, которая показывает, где машины, как они используются, сколько зарабатывают и где теряются деньги — без замены уже установленных GPS/TMS. Для РФ: слой ИИ-агентов (топливо, маршруты, диспетчеризация, ТО, спецразрешения) поверх телематики. |
| **Target audience** | **ICP:** автопарки **5–200 ТС** — доставка, FTL/LTL, негабарит, сервисный флот, каршеринг/LCV. **Пилот #1:** 6 ТС, Wialon Local, ТрансМенеджер, Росдор + 1С. **ЛПР:** владелец, ком. директор, руководитель автопарка, главный диспетчер. |

## 2. Problem

| Поле | Значение |
|------|----------|
| **Problem statement** | Операторы не видят полную картину: загрузка, геопозиция, стоимость эксплуатации и доходность **каждой машины в одном месте**. Данные размазаны по Wialon, TMS, Excel, 1С и Росдор; диспетчер вручную переносит заявки; спецразрешения занимают часы. |
| **Current alternatives** | Excel/Google Sheets; «голая» телематика без финансов; TMS без ИИ; аутсорс разрешений; enterprise-монстры; кастомные интеграции 1С. |
| **Why now** | Рост рынка коммерческой телематики; давление на маржу; штрафы негабарит; дефицит диспетчеров; GPS/TMS уже стоят — нужна **надстройка**, не rip-and-replace. |

## 3. Value Proposition

| Поле | Значение |
|------|----------|
| **Key value** | ① Консолидация телематики, заявок, финансов и операций по каждому авто; ② P&L / ROI и utilization — какие машины зарабатывают; ③ ИИ-агенты: топливо, маршруты, dispatch, ТО, **Permit + Росдор**. |
| **Differentiation** | Фокус **5–200 ТС** (не enterprise-монстр); не заменяем Wialon/ТМ; Permit Agent для негабарита; human-in-the-loop; хостинг РФ / 152-ФЗ; Founding ₽49K/мес. |

## 4. MVP

### 4.1 MVP goal (продукт)

Проверить, что владельцы/операторы **готовы платить** за единый кабинет: трекинг + базовая аналитика + 1–2 телематических провайдера + ROI.

### 4.2 MVP goal (пилот 6 ТС)

Доказать сквозной контур **Wialon → ТМ → Permit → ROI** за 6–8 недель с измеримым −30–50% времени на заявки и разрешения.

### 4.3 MVP scope

| # | Сценарий | Product Area |
|---|----------|--------------|
| 1 | Регистрация компании, роли, добавление ТС (марка, VIN, госномер, класс) | Fleet Core |
| 2 | Интеграция **Wialon** Tier 1: карта realtime, пробег, топливо | Telematics |
| 3 | Чтение заявок **ТрансМенеджер** | Integrations |
| 4 | **P&L / ROI** по машине и автопарку | Financial Analytics |
| 5 | **Utilization** — работа vs простой | Financial Analytics |
| 6 | **Permit Agent** + Росдор: analyze, HITL, реестр | Core Product / AI |
| 7 | **Fuel Agent**: baseline + алерты | Core Product / AI |
| 8 | Тарифная сетка Small / Growing / Pro | Billing |
| 9 | **1С** — CSV-сверка затрат (пилот) | Integrations |

### 4.4 Out of scope (MVP)

- ML-оптимизация маршрутов enterprise-уровня
- Глубокая многовалютная бухгалтерия
- Playwright ЛК urm.safe-route.ru
- Полный API 1С
- Маркетплейс аренды
- Мобильное приложение водителя
- ЮKassa billing (после пилота)

## 5. Metrics

| Метрика | Определение | Target MVP |
|---------|-------------|------------|
| **North Star** | Активные машины с телематикой + регулярные сессии (WAU) **и/или** подтверждённая экономия ₽/мес | ≥6 машин пилота daily; ₽80K экв. экономии |
| **Activation** | Клиент: ≥1 машина + провайдер подключён + дашборд 3×/нед | ≥70% заявок через FleetPilot (пилот) |
| **Retention** | D30/D90 retention аккаунтов; WAU диспетчеров | 2/2 champion 4+ нед |
| **Business** | MRR, ARPU, доля автопарков >10 машин | 1 paid Pro после пилота |

## 6. Risks

| Категория | Риск | Митигация |
|-----------|------|-----------|
| Product | Сложно встроиться в существующую телематику | Надстройка, не замена |
| Product | Мало данных на 6 ТС для ML | Rule-based + HITL |
| Technical | Несколько провайдеров, нестабильный API | Adapter pattern, retry, audit log |
| Technical | Wialon Local LAN-only | VPN / sync-agent |
| GTM | Узкая ниша, сложно достучаться до ЛПР | Case study пилота, fleetpilot.ru |
| GTM | 152-ФЗ | Договор ПДн, хостинг РФ |
